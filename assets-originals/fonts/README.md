# Písmo pre PDF

`DejaVuSans.ttf` je nemodifikovaná kópia písma DejaVu Sans z lokálneho balíka Poppler. Do PDF sa vkladá podmnožina použitých znakov. Písmo podporuje slovenskú, českú, anglickú, nemeckú a španielsku diakritiku.

Licencia je uložená v `LICENSE-DejaVu.txt`. Jej zdroj: https://raw.githubusercontent.com/dejavu-fonts/dejavu-fonts/master/LICENSE . Projekt: https://dejavu-fonts.github.io/ .

Písmo a licenciu uchovávame spolu, aby generovanie PDF nevyžadovalo internet ani závislosť od písiem nainštalovaných v počítači.
