# Pravidlá projektu

- Nikdy nepoužívaj znak s kódom U+2014 (em dash). Namiesto neho používaj bežný spojovník `-` (U+002D).
- Toto pravidlo platí pre odpovede, obsah webu, dokumentáciu, komentáre aj metadáta repozitára. Nepoužívaj ani HTML entity alebo Unicode escape sekvencie, ktoré by vykreslili zakázaný znak.
